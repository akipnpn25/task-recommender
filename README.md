# 今やる課題推薦アプリ

大学生向けの課題推薦アプリです。

課題がいくつかあるときに、「今どの課題からやればいいか分からない」ということがよくあるため、締切や残り作業時間、空き時間などから、今取り組む課題をおすすめするアプリを作りました。

## 主な機能

* 課題の追加・編集・削除
* 課題の進捗管理
* 今取り組む課題を最大3件推薦
* 曜日ごとの空き時間設定
* 特定の日だけ空き時間を変更
* 締切までに時間が足りるかの判定
* 完了した課題の管理

## 推薦の仕組み

推薦するときは、主に以下の情報を使っています。

* 締切までの時間
* 課題の残り作業時間
* 現在の進捗
* 今使える時間
* 今後確保できる時間
* 他の課題に必要な時間

例えば、締切が近い課題だけを見るのではなく、複数の課題をすべて考えたときに、どの締切から時間が足りなくなりそうかも計算しています。

時間不足が起こりそうな場合は、その締切までに終わらせる必要がある課題を優先しておすすめします。

また、今使える時間の中で終わらせやすいかどうかも推薦に反映しています。

## 工夫したところ

一般的なToDoアプリでは、締切順などで課題を整理することはできますが、最終的にどの課題から取り組むかは自分で決める必要があります。

そこでこのアプリでは、課題そのものの締切だけではなく、今後使える時間と複数課題の残り作業時間を比較するようにしました。

進捗率も考慮しており、例えば4時間かかる課題が50%まで進んでいれば、残り2時間として計算します。

また、推薦結果だけを表示するのではなく、「締切が近い」「この締切までに時間が不足する」など、おすすめした理由も確認できるようにしました。

## デザイン

大学生がカフェで課題をするときに使うイメージで、アイボリーやブラウンを中心とした落ち着いたデザインにしています。

機能を増やしすぎて見づらくならないように、「今日」「課題一覧」「課題追加」の3つに画面を分けました。

## テスト

推薦部分はpytestを使ってテストしています。

現在は、以下のようなケースを確認しています。

* 進捗率から残り作業時間を計算できるか
* 時間不足になる締切を検出できるか
* 締切が近い課題を優先できるか
* 時間不足になる締切までの課題を優先できるか
* 今の空き時間が推薦に反映されるか

現在のテスト結果は7件すべて成功しています。

```bash
pytest -v
```

```bash
pip install -r requirements.txt
streamlit run app.py
```
